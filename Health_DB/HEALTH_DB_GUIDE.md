# Health_DB 구조 가이드

## 개요

건강/운동 기록, 건강 지식, 깨달음(공유용 인사이트) 노트를 관리하는 데이터베이스.

## 문서 유형

| 유형 | 성격 | 폴더 | 설명 |
|------|------|------|------|
| **데일리** | 반복 생성형 | `Health_데일리/{YYYY-MM}/` | 매일 기록. 운동, 식단, 인바디, 영양제 |
| **건강지식** | 축적형 (갱신) | `Health_지식/` | 건강 관련 지식 정리. 수시 업데이트 |
| **깨달음** | 완성형 (게시용) | `Health_깨달음/` | 지식을 소화한 인사이트. SNS 공유용 |

보조 허브 문서:

| 유형 | 폴더 | 설명 |
|------|------|------|
| **주제** | `Health_주제/` | 주제별 허브. 관련 문서를 wikilink로 묶음 |

## 폴더 구조

```
/Health_DB
├── Health_DB.base               # Bases 데이터베이스 (4개 뷰)
├── HEALTH_DB_GUIDE.md           # 이 문서
├── Health_데일리/                # 매일 기록 (월별 하위 폴더)
│   └── {YYYY-MM}/
│       └── {YYYY-MM-DD}.md
├── Health_지식/                  # 건강 지식 (주제별, 갱신형)
│   └── {topic_name}.md
├── Health_깨달음/                # 인사이트 (SNS 게시용)
│   └── {title}.md
├── Health_주제/                  # 주제 허브 (wikilink)
│   └── {topic_name}.md
└── Health_템플릿/                # 템플릿 (원본 보존)
    ├── Daily_template.md
    └── Knowledge_template.md
```

## 상태값

### 건강지식 상태

| 상태 | 설명 |
|------|------|
| 학습중 | 아직 정리 중 |
| 정리완료 | 내용 정리 완료 |

### 깨달음 상태

| 상태 | 설명 |
|------|------|
| 작성중 | 초안 작성 중 |
| 검토중 | 내용 검토/수정 중 |
| 게시완료 | SNS에 게시 완료 |

## 위키링크 규칙

- 속성(frontmatter)에는 `"[[허브명]]"` (따옴표 필수)
- 본문에는 `[[문서명]]` (따옴표 없이)
- 쌍방향 필수: A→B 링크 시 B→A 백링크도 추가
- 주제 허브가 없으면 즉시 생성

## Bases

Dataview 대신 Obsidian 코어 플러그인 **Bases** 사용:
- `Health_DB.base` 파일로 동적 테이블 뷰 생성
- 4개 뷰: 데일리 전체, 인바디 추적, 건강지식, 깨달음/게시
- Properties 기반 필터링/정렬
