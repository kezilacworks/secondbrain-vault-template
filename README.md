# KEZ 세컨드브레인 — 지식저장소 템플릿

이 저장소는 KEZ 세컨드브레인 시스템이 사용하는 Obsidian vault의 시작 템플릿이에요. 이식 마법사가 이 저장소를 기반으로 여러분만의 지식저장소 repo를 만들어드려요.

## 이 저장소는 무엇인가요

- `Contents_DB/` · `Scrap_DB/` · `Health_DB/` — 감상 기록·스크랩·건강 기록을 담는 기본 데이터베이스 폴더예요.
- `W01_{워크스페이스명}/` — 업무·프로젝트를 정리하는 폴더예요. 실제 사용 시 폴더명을 원하는 이름으로 바꾸고, 그 안에 `프로젝트 > 기획 > 업무` 구조로 노트를 쌓아가시면 돼요.
- `Inbox/` — 분류하기 전에 일단 담아두는 환승센터예요.
- `.build/` — 노트를 인덱싱하는 빌드 도구가 들어있어요. 직접 실행할 일은 없고, GitHub Actions가 자동으로 사용해요.
- `.github/workflows/build-index.yml` — `main` 브랜치에 push할 때마다 자동으로 인덱스를 다시 만들어주는 워크플로예요.

## 처음 push하면 무슨 일이 일어나나요

첫 push 후 GitHub Actions가 자동으로 실행되면서 `*_META.md`(사람이 보기 좋은 요약 테이블)와 `SEARCH_CORPUS.json`(검색용 데이터)이 저장소 루트에 만들어져요. 몇 분 정도 걸릴 수 있어요. Actions 탭에서 진행 상황을 확인할 수 있어요.

## 직접 수정하지 말아야 할 것들

아래 파일들은 Actions가 자동으로 만들고 관리해요. 직접 고치면 다음 push 때 사라지니 건드리지 마세요.

- `CONTENTS_META.md` · `SCRAP_META.md` · `WORKS_META.md`
- `SEARCH_CORPUS.json`
- `INDEX.md`

노트 내용은 각 폴더 안에서 자유롭게 만들고 고치시면 돼요. frontmatter의 필드명(카테고리·장르·상태 등)은 인덱서가 인식하는 약속된 이름이니 그대로 유지해주세요.
